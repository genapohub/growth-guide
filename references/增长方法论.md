# 增长方法论

## 一、场景识别

| 场景 | 名称 | 判断条件 | 产出量 |
|------|------|---------|--------|
| 场景一 | 0→1 增长体系搭建 | 新产品、无增长模型、无获客渠道 | 10-12类 |
| 场景二 | 中大型增长项目 | 新渠道拓展、增长模型重构、大型Campaign | 6-8类 |
| 场景三 | 小优化/渠道调整 | 单渠道优化、素材AB测试、文案调整 | 2-3类 |
| 场景四 | 增长引擎升级 | 从付费投放→内容+社区驱动增长 | 8-10类 |
| 场景五 | 增长探索/策略研究 | 新渠道可行性、竞品增长策略拆解 | 3-4类 |

## 二、场景一产出清单

1. 市场洞察（TAM/SAM/SOM、竞争格局）
2. 用户分层模型（AARRR海盗模型/RFM/生命周期分层）
3. 增长模型（北极星指标+增长公式+驱动因子拆解）
4. 获客渠道矩阵（付费/免费/内容/病毒/BD各渠道ROI预估）
5. 内容增长策略（品类矩阵/内容日历/SEO关键词体系）
6. 投放策略（预算分配/出价策略/定向策略/素材策略）
7. 激活与转化方案（Aha Moment定义/新用户引导/转化漏斗优化）
8. 留存策略（Push/短信/邮件/站内触达体系）
9. 推荐与裂变方案（邀请机制/激励设计/病毒系数K-factor）
10. 增长仪表盘（核心指标看板/渠道归因/ROI追踪）
11. 增长实验体系（实验流程/假设库/优先级ICE评分/实验日历）
12. 团队OKR与增长节奏（季度增长目标/周迭代节奏）

2. 渠道策略方案（投放+素材+落地页完整链路）
3. 增长实验设计（假设/变量/样本量/评估标准）

## 四、场景三产出清单

1. 单渠道ROI分析
2. 素材/文案AB方案
3. 优化效果追踪

1. 增长方向探索报告
2. 竞品增长策略拆解（获客/激活/留存/变现全链路）
3. 渠道可行性评估矩阵
4. 增长趋势与工具调研

## 七、增长通用规范

### 增长模型规范
- 顶级公式：北极星 = 获客量 * 激活率 * 留存率 * 变现ARPU * 推荐系数
- 每个驱动因子至少对应1个可执行项目
- 增长模型每季度Review一次，随业务阶段调整权重

### 渠道策略规范
- 每个渠道评估5个维度：规模/精准度/成本/可控性/可持续性
- 渠道结构遵循「721」原则：70%稳定渠道、20%成长渠道、10%探索渠道
- 单一渠道依赖度不超过总获客量的50%

### 实验规范
- 实验假设使用「如果...那么...因为...」格式
- ICE评分排序：Impact影响力、Confidence信心、Ease成本（每项1-10分）
- 实验记录模板：假设/设计/结果/学习/下一步
- 实验周期：产品实验≥1周、渠道实验≥1个投放周期

### 内容增长规范
- 关键词策略覆盖：品牌词/品类词/长尾问题词/竞品词
- 内容更新频率：核心页面月度、博客周度、社交媒体日度
- 内容转化路径必须闭环：曝光→点击→落地→转化→追踪

## 八、产出质量检查清单

- [ ] 北极星指标清晰可量化
- [ ] 增长模型可拆解到可执行项目
- [ ] 获客渠道覆盖付费+免费+内容三大类
- [ ] 留存体系分层触达
- [ ] 实验假设库≥20条可执行假设
- [ ] ROI预估有依据（参照历史数据或行业基准）
- [ ] 归因模型明确（首次点击/末次点击/线性/时间衰减）
- [ ] 团队OKR与增长目标对齐
- [ ] 竞品分析有可执行的差异化策略
- [ ] 所有策略有明确的衡量指标和时间节点
